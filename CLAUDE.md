# AI Personal Command Center

Personal dashboard that syncs Gmail, Google Calendar and SUCourse (Moodle iCal) into Postgres, uses Claude to extract deadlines and tasks from emails, and has a chat agent that answers questions like "What do I need to finish before Friday?"

## Stack
- Backend: FastAPI, Python 3.12, managed with uv (run everything with `uv run ...` from `backend/`)
- Database: PostgreSQL 17 + pgvector (Homebrew), database `command_center`, migrations with Alembic
- LLM: Anthropic API via the `anthropic` SDK; models set in `backend/.env` (EXTRACT_MODEL, AGENT_MODEL)
- Embeddings: nomic-embed-text via Ollama (768 dims)
- Frontend: React + Vite + TypeScript, Tailwind, TanStack Query (in `frontend/`)
- Machine: M1 MacBook Air, 8 GB RAM

- Done (Milestone 3): Gmail sync in `app/sync/gmail.py` (first run: last 30 days minus promotions/social; later runs: history.list from the saved historyId, full-run fallback on 404), upsert into items, POST /sync/gmail. The Cloud project's Gmail quota is ~550 units/user/minute, so calls are throttled (`UNITS_PER_MINUTE`) and a first run takes ~4 min
- Done (Milestone 4): extraction in `app/llm/extract.py` (one forced save_extraction tool call per email, Pydantic-validated, tasks saved with created_by="extraction", one-sentence summary in items.summary, usage logged to llm_usage), POST /extract/run?limit=10. Sensitive-email filter: subjects/senders matching `SENSITIVE_PATTERNS` (OTPs, passwords, bank alerts) are marked "Skipped: sensitive email" and never sent to Claude; the prompt also forbids codes, passwords, account numbers and amounts in titles/summaries. Before any text goes to Claude (extraction, cleanup, evals), `app/llm/redact.py` masks Pakistani CNICs, card numbers (Luhn-checked), IBANs (mod-97-checked) and phone numbers as [REDACTED-<LABEL>]; all patterns are in its REDACTIONS list, and `uv run python -m app.llm.redact` counts matches in stored emails. Tests in `backend/tests/` (`uv run pytest`). Full inbox run: 406 emails, 0 failures, 16 tasks, 45 skipped as sensitive, ~$1.30
- Done (Milestone 5): Google Calendar sync in `app/sync/calendar.py` (primary calendar, next 60 days, singleEvents, all-day events at Europe/Istanbul midnight, events that vanish from the window are deleted, past ones kept) and SUCourse sync in `app/sync/sucourse.py` (Moodle .ics export URL saved in sync_state via POST /sync/sucourse/url and never echoed or logged; each VEVENT becomes an assignment item plus a task with created_by="sucourse", priority high if due within 3 days). POST /sync/calendar, /sync/sucourse, /sync/all. No LLM calls. Tests in `tests/test_sync.py`
- Done (Milestone 6): chat agent in `app/llm/agent.py`, endpoints in `app/llm/agent_routes.py`. POST /chat runs a manual tool-use loop (max 5 model calls) with AGENT_MODEL. Read tools list_tasks, list_events, search_items run SQL and never return email bodies, sensitive or noise emails. create_task is saved to pending_actions and only runs on POST /actions/{id}/confirm (or /cancel). Each call is logged to llm_usage as purpose="agent". Tests in `tests/test_agent.py` use a fake Anthropic client
- Done (polish before evaluation): POST /sync/all now also runs extraction on up to EXTRACT_ON_SYNC_LIMIT (default 50) unprocessed emails and returns its counts and estimated cost; the shared run lives in `app/sync/runner.py`. A process-wide lock means only one sync or extraction runs at a time (a second one gets 409). `app/scheduler.py` runs the same thing every 30 minutes with APScheduler inside the API process (max_instances=1, first run 30 min after startup so `--reload` restarts don't trigger it), for every user with a stored Google token; users needing reconnect are skipped, and each run logs counts and cost (no titles). Switch it off with BACKGROUND_SYNC_ENABLED=false. Only run one uvicorn worker, or each worker would schedule its own job. SUCourse titles containing a word from EXAM_KEYWORDS in `app/sync/sucourse.py` (Mid, Midterm, Final, Exam, Quiz) are high priority, "... opens" events stay low, and every SUCourse sync re-scores all open SUCourse tasks except ones whose priority you changed (PATCH /tasks/{id} sets tasks.priority_set_by_user). Tests in `tests/test_background.py` and `tests/test_sync.py`
- Cost estimates come from the price table in `app/llm/pricing.py` (keyed by model name, dated ids map to their alias). A model missing from the table gives estimated_cost_usd = null, so add a row when changing EXTRACT_MODEL or AGENT_MODEL
- Done (Milestone 7): dashboard endpoints in `app/dashboard/` (GET /today returns open tasks grouped into overdue / today / this_week plus today's events and the next 5 SUCourse items, already sorted; GET /tasks?status=open|done|expired; PATCH /tasks/{id} for status and priority). After Google login the backend redirects to FRONTEND_URL. The agent's list_tasks also returns open undated tasks when a date filter is used, and the prompt asks Claude to mention them in one line. Tests in `tests/test_dashboard.py`
- Done (Milestone 8): extraction eval in `backend/evals/` (see its README). `uv run python -m evals.export` writes ~60 varied processed emails (no sensitive/noise) to `evals/emails.jsonl`, which is gitignored and must never be committed. You label them at #/label, backed by dev-only `/evals/...` endpoints in `app/dev/routes.py` (localhost only, off with DEV_ENDPOINTS_ENABLED=false) that never return the model's prediction. `uv run python -m evals.run` extracts each labeled email with its sent time as today and no open tasks, scores actionable accuracy, task recall/precision (word-overlap title matching, no LLM judge) and due dates (same day, time within 1 h), and writes a Markdown report to `evals/results/` (subjects only, no bodies). Bump `PROMPT_VERSION` in `extract.py` when changing the prompt. Tests in `tests/test_evals.py`
- Frontend in `frontend/` (React + Vite + TypeScript, Tailwind v4, TanStack Query, Node 22 via `.nvmrc`). The Vite dev server proxies /auth, /me, /today, /tasks, /chat, /actions, /sync and /evals to :8000, so the session cookie works without CORS. Pages use hash routes (#/tasks, #/chat) so they never collide with those API paths. Colors are CSS variables in `src/index.css` (one accent, dark mode via prefers-color-scheme or the toggle). Run: `uv run uvicorn app.main:app --reload` in backend/, `npm run dev` in frontend/, open http://localhost:5173
